# プロジェクト管理アプリ (Gantt & Burnup)

デスクトップ対応のプロジェクト管理アプリケーションです。Tauri v2とSvelteKitを使用して構築されており、洗練されたUI（shadcn-svelte + TailwindCSS）と直感的な操作性を提供します。

## 主な機能

- **ガントチャート:** タスクとサブタスクの期間を視覚的に管理。
- **バーンアップチャート:** サブタスクの完了状況をグラフ化し、理想の進捗と実績を比較。
- **タスク詳細パネル:** タスクをダブルクリックして、名前、期間、タグ、メモを編集可能。
- **休日対応:** 日本の祝日API（holidays-jp）と連携し、土日祝日を稼働日計算から除外。
- **カスタマイズ:** ダークモード/ライトモードの切り替え、アクセントカラーの変更に対応。

## 技術スタック

- Tauri v2 (デスクトップアプリ化)
- SvelteKit (UIフレームワーク)
- shadcn-svelte & bits-ui (コンポーネント)
- TailwindCSS (スタイリング)
- Chart.js (グラフ描画)

## インストーラーについて

Windows向けの日本語版インストーラー（MSIおよびNSIS）を作成するように `tauri.conf.json` が設定されています。
Windows環境でビルドを実行することでインストーラーが生成されます。

## 開発の始め方

```bash
npm install
npm run dev &
npm run tauri build
```
