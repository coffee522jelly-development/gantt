# プロジェクト管理アプリ (Gantt & Burn-up Chart)

ガントチャートとバーンアップチャートを同時に管理できる、ブラウザベースのプロジェクト管理アプリケーションです。将来的にTauri v2を用いたデスクトップアプリ化を見据え、フロントエンド技術（HTML, CSS, JavaScript）のみで構築されています。

## 主な機能

* **ガントチャート**
  * タスクの追加・削除
  * ドラッグ＆ドロップでのタスクの並び替え（SortableJS使用）
  * マウス操作（ドラッグ）による期間の移動・伸縮
  * サブタスクのインライン表示・管理
  * タスク完了日の記録と表示機能
* **バーンアップチャート**
  * サブタスクの総数に対する完了度合いの可視化（Chart.js使用）
  * 理想の計画ラインと実際の実績ラインの比較
  * チャートのPNG画像エクスポート機能
* **休日管理・営業日計算**
  * プロジェクト全体の期間設定
  * 外部API（`https://holidays-jp.github.io/api/v1/date.json`）連携による日本の祝日の自動取得
  * 個別のカスタム休日設定機能
  * 土日・祝日・カスタム休日を除外した営業日ベースでのスケジュール・グラフ計算
* **データ保存**
  * `localStorage`を用いたデータのローカル保存機能

## 使用技術 (MITライセンス)

* HTML5 / CSS3 / Vanilla JavaScript
* [Tailwind CSS](https://tailwindcss.com/) (CDN) - スタイリング
* [SortableJS](https://sortablejs.github.io/Sortable/) (CDN) - ドラッグ＆ドロップ操作
* [Chart.js](https://www.chartjs.org/) (CDN) - グラフ描画

## 使い方

1. このリポジトリをクローンまたはダウンロードします。
2. 任意のローカルサーバー（例: `python3 -m http.server 8000`）を立ち上げます。
3. ブラウザで `http://localhost:8000` にアクセスします。
4. ヘッダーの右上にある「開始」「終了」からプロジェクトの期間を設定して使用を開始してください。
